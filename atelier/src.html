Guide de l'Atelier Dracombra

Chaque onglet est un espace de travail avec son propre projet. Changer d'onglet enregistre le projet en cours et rouvre le dernier projet de l'onglet choisi.

Personnage

  1. Ouvre la fiche ChatGPT (face, dos, profil) sur fond magenta.
  2. Détourage : étape 1 à gauche (fond, liseré rose). Grille : étape 2 (taille des gros pixels). Couleurs : étape 3 (éclat, nombre de couleurs, palette Dracombra).
  3. Découpe : étape 4, sprites séparés, case « Perso HD 48×64 » pour tous les personnages.
  4. Retouche : crayon, gomme, pot, pipette, calques, symétrie (M), recoloration.
  5. Main (A) : clic sur la main, glisser pour l'angle de l'outil, devant ou derrière. Miroir pour le profil gauche.

Animation

  1. Ajoute les planches de marche ou d'action (section Planches, « + Ajouter une planche »), découpe en Grille fixe (4×1 marche, 3×1 action).
  2. Nomme chaque image : animation + direction (marche, bas…). Règle la durée des images.
  3. Mouvement : peins les parties (P), choisis un mouvement ou apprends-le d'une animation réussie, applique.
  4. Animer : respiration, dégât, rebond en un clic. Pelure (O) pour retoucher image par image.

Objets & armes

  1. Une planche ChatGPT avec tous les outils, verticaux, manche en bas.
  2. Chaque objet reçoit un point de prise (outil « Prise » pour corriger). Renomme : hache, pioche, epee…
  3. Recolorer : variantes bois, fer, or… en un clic.
  4. Nomme le projet outils et exporte dans le même dossier que les personnages.

Tuiles

  1. Taille 32×32 par défaut. Une texture par matière (herbe, terre, chemin…), renommée.
  2. Rendre raccordable, puis vérifie la mosaïque.
  3. Créer le raccord entre deux matières : 16 tuiles de bords et coins.
  4. Essaie sur la vue Carte, puis exporte le TileSet.

Bâtiments

  1. Une planche de pièces : murs, toits, portes, fenêtres.
  2. Vue Plan : pose les pièces, aimant réglable, devant/derrière, miroir.
  3. Peins l'empreinte, la zone bloquante, la porte.
  4. Étapes du chantier, puis exporte une scène par bâtiment.

Décors & ressources

  1. Une planche : chaque décor entier (arbre, rocher, buisson, lin…), puis sa souche ou son état récolté, éventuellement ses repousses.
  2. Donne le même nom à tous les états d'un décor (chene, rocher…) et choisis l'État de chaque image.
  3. Pied (A) : point posé au sol. Collision (C) : rectangle à la base. « Copier sur tous les états ».
  4. Ressource : ce qu'il donne, combien, en combien de coups, avec quel outil, temps de repousse. L'aperçu montre le cycle.

Version et mises à jour

Atelier

La page en ligne se met à jour toute seule.

Dans Godot

  • Paramètres du projet > Rendu > Textures : filtre Nearest.
  • Personnage : glisse nom.tscn ; animations marche_bas, frappe_droite… ; outil en main avec equiper("hache_fer").
  • Tuiles : TileMapLayer > Tile Set = nom.tres, onglet Terrains, Terrain Set 0.
  • Bâtiments : scène posée par son coin bas-gauche, etape, avancer(), cases_occupees().
  • Décors : scène posée par son pied ; frapper("hache_fer") renvoie la quantité récoltée ; groupe ressources.
  • Le .exe écrit directement dans le dossier du jeu (« Choisir le dossier… »).

Ressource

min (0 = jamais)

États : entier obligatoire ; abîmé, récolté et les repousses sont facultatifs. Outil Pied (A) : point posé au sol. Outil Collision (C) : rectangle à la base, là où le héros bute.

Tuiles

Renomme chaque tuile de matière (« Nom » plus haut) : herbe, terre, chemin, eau…

Raccord entre deux matières

Carte d'essai

Vue « Carte » : peins pour voir les raccords se placer tout seuls, comme dans Godot.

Mouvement

1. Peins les parties du corps sur l'image de base. 2. Choisis un mouvement. 3. Applique : les images sont créées, à retoucher ensuite.

Articuler une partie

Outil Articuler (R) : choisis une partie ci-dessus, puis glisse sur le dessin. Maj = ligne droite ou crans de 15°. Flèches = 1 pixel. Le pivot (rond blanc) se place tout seul, ou avec « Pivot ». Agit sur le calque actif.

Apprendre : choisis une animation réussie d'un personnage dont l'image de base (idle, même direction) a ses parties peintes. Le mouvement est gardé pour tous tes projets.

Animer

Crée une animation à partir de l'image choisie. Les nouvelles images s'ajoutent à la liste, prêtes à retoucher.

Projets

Copies de secours

Les 10 dernières versions, rangées dans le dossier « sauvegardes » à côté du fichier. Revenir à une version l'ouvre ; « Enregistrer » la remet ensuite dans le fichier.

Planche en PNG
